# Jagadeesh Goud — Cybersecurity + AI Portfolio

A responsive, bilingual (English/German) static portfolio website.

## Files
- `index.html` — page content
- `styles.css` — responsive design
- `script.js` — language toggle and footer year
- `assets/Jagadeesh_Goud_CV.docx` — CV supplied from the user's Library

## Preview locally
Open `index.html` in a browser.

## Publish
Upload the contents of this folder to the root of a static hosting repository. Enable the host's static-site publishing feature for the `main` branch and `/ (root)`.

## Accuracy notes
- Learning topics are presented as study/exploration unless a hands-on activity was explicitly described.
- Nmap/Wireshark, Packet Tracer and Kali/Linux activities are identified as practical exercises.
- The CV is included as a downloadable DOCX.
- Review the CV and public contact details before publishing. Add an Impressum and privacy notice if required for your intended use in Germany.
